## F01：タスク作成 {#f01}

**概要**
ユーザーが新しいタスクを作成できる。

**入力項目**

| 項目名 | 必須 | 型 | 備考 |
|--------|------|----|------|
| タイトル | ✓ | テキスト | 最大100文字 |
| 説明 | | テキスト | |
| 担当者 | | ユーザー選択 | |
| 期限 | | 日付 | |
| ステータス | ✓ | 選択 | 初期値：未着手 |
| 優先度 | | 選択 | 高・中・低 |

**正常系**
- 必須項目を入力して送信すると、タスクが作成され一覧に追加される

**異常系**
- タイトルが未入力の場合、エラーメッセージを表示する

## F02：タスク編集 {#f02}

**概要**
既存タスクの内容を変更できる。

**仕様**
- タスク一覧の行をクリックすると編集モーダルが開く
- 編集可能な項目：タイトル・説明・ステータス・優先度・期日
- 「保存」ボタンで変更を送信し、成功するとモーダルを閉じて一覧を最新化する
- タイトルは必須。空の場合は保存ボタンが無効になる
- 通信エラー時はモーダル内にエラーメッセージを表示する

---

## F03：タスク削除 {#f03}

**概要**
タスクを削除できる。

**仕様**
- 削除前に確認ダイアログを表示する
- 削除したタスクは復元できない

---

## F04：タスク一覧表示 {#f04}

**概要**
タスクを一覧で確認できる。

**表示項目**
- タイトル、ステータス、担当者、期限、優先度

**並び替え**
- 並び替えドロップダウンで選択：優先度順・期日順・作成日順（新しい順）
- 優先度順：高 → 中 → 低 → 未設定 の順に並び替える
- 期日順：期日の近い順に並び替え、期日未設定は末尾

## F09：タスク並び替え {#f09}

**概要**
タスク一覧の表示順を変更できる。

**仕様**

| 操作 | 動作 |
|------|------|
| 並び替えドロップダウン | 優先度順・期日順・作成日順（新しい順）から選択して一括ソート |

**並び順の保存**
- ソート順はフロントエンドのステート管理で保持する（ページリロードで初期値に戻る）
- 将来的にはドラッグ&ドロップによる手動並び替えも対応予定
