## F01：タスク作成 {#f01}

**概要**
ユーザーが新しいタスクを作成できる。

**入力項目**

| 項目名 | 必須 | 型 | 備考 |
|--------|------|----|------|
| タイトル | ✓ | テキスト | 最大100文字 |
| 説明 | | テキスト | |
| 担当者 | | ユーザー選択 | |
| 期限 | | 日付 | |
| ステータス | ✓ | 選択 | 初期値：未着手 |
| 優先度 | | 選択 | 高・中・低 |

**正常系**
- 必須項目を入力して送信すると、タスクが作成され一覧に追加される

**異常系**
- タイトルが未入力の場合、エラーメッセージを表示する
